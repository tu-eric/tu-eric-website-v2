## Updating these items

To replace a PDF, overwrite the existing file using the same name. If the poster design changes, replace its corresponding `assets/posters/<id>.webp` thumbnail as well. To add an entry, copy one of the `<article class="poster-card poster-card--pdf">` blocks in `research.html` and edit its title, conference, file paths, alt text, and year.

The **Open research resources** filter on `publications.html` is based on data, code, preregistrations, and materials, not poster links.
